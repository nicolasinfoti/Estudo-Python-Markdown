# Calculadora de Média.
## Calcular a média entre duas notas, e trazer retorno aprovado ou reprovado.

# Tecnologias Utilizadas:
       Python 3.14(64-bit)

# Como executar:
       Pode se usar uma IDE ou compliadores online.

### Comandos via terminal:
       python python/app.py
       py python/app.py
